# Lumencuit

Lumencuit은 Unity로 개발한 타일 기반 색 신호 퍼즐 게임입니다.
플레이어는 제한된 회로 요소를 배치하여 색 신호를 목표 지점까지 전달하고, 각 스테이지의 조건을 만족시켜야 합니다.

이 레포지토리는 포트폴리오 검토를 위해 일시적으로 공개한 버전입니다. 이후 다시 비공개로 전환될 수 있습니다.

## 실행 방법

### Unity Editor에서 실행

1. Unity `6000.3.16f1` 이상 버전에서 프로젝트를 엽니다.
2. 스테이지 선택 씬에서 Play 버튼을 눌러 실행합니다.

### Windows 빌드 파일

압축을 해제한 뒤 실행 파일을 실행합니다.

빌드 파일은 **Windows 64-bit** 환경을 대상으로 합니다.
화면 비율은 **16:9** 기준으로 테스트되었습니다.

빌드 실행 확인 환경은 다음과 같습니다.

* OS: Windows 11 Education
* CPU: AMD Ryzen 5 5600X

## 개발 환경

* Unity: `6000.3.16f1`
* IDE: Visual Studio Community 2026 `18.7.2`

## 조작 방법

| 입력      | 동작              |
| ------- | --------------- |
| ESC     | 스테이지 선택창으로 돌아가기 |
| Q + 좌클릭 | 회로 요소 제거        |
| 우클릭     | 회로 요소 제거        |
| 회로 요소 선택 후 좌클릭 | 회로 요소 배치            |
| W + 좌클릭 드래그 | 선 연결            |
| R       | 스테이지 재시작        |
| Z       | Undo            |
| X       | Redo            |

## 로그 및 저장 파일 위치

Windows 빌드 기준 로그 파일과 저장 파일은 다음 경로에 생성됩니다.

로그 파일:

```text
C:\Users\<사용자 이름>\AppData\LocalLow\DefaultCompany\Lumencuit\Logs\
```

저장 파일:

```text
C:\Users\<사용자 이름>\AppData\LocalLow\DefaultCompany\Lumencuit\Saves\
```
